# 京都TECH学園祭アプリ（フロントエンド）

学園祭の来場者がブース、呼び出し番号、イベント、お知らせ、校内マップを確認し、店舗側が受付番号・会計・待ち時間を管理するためのWebアプリです。
`docs/frontend.md` の仕様に基づき、React 18 + Vite 6 + React Router 7 + Tailwind CSS 4 で実装しています。

## 起動方法

```bash
npm i
npm run dev      # 開発サーバー
npm run build    # 本番ビルド
npm run preview  # ビルド結果の確認
npm run typecheck # 型チェック（任意）
```

## 画面構成

### 来場者向け（共通シェル：ヘッダー＋下部タブナビ）

| パス | 画面 | 内容 |
| --- | --- | --- |
| `/` | ホーム | ヒーロー動画、待ち人数が少ないブース、クイックメニュー |
| `/attractions` | ブース待ち状況 | ブース一覧（待ち人数）、詳細、マップリンク |

## データについて

来場者向けのブース、ホームおすすめ、校内マップ、呼び出し番号はバックエンド API から取得します。
店舗ログイン、ログアウト、ダッシュボード、レジ（会計と精算）、呼び出し、提供済み、待ち人数もバックエンド接続済みです。
管理画面（店舗 CRUD・集計など）もバックエンド接続済みです。
`localStorage`（キー `kt_festival_state_v1`）に残るのは、ログイン情報と「大きく表示」している番号だけです。
モバイルオーダー／予約は行わず、店頭購入後の受取番号確認を行います。

## テーマ

- ヘッダー右上のボタンでライト／ダークを切替（`localStorage('theme')` に保存）
- 初回は OS の `prefers-color-scheme` に追随
- 配色定義は `src/styles/theme.css`（CSS変数 ＋ `@theme`）
